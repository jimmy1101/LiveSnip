## 🌟 核心特性

### 1. 微信同款“原地文字划选复制”（Live Text）
* **0 延迟贴图呈现**：按下 F3 或鼠标中键贴图瞬间置顶，后台线程毫秒级异步执行本地离线 OCR 推理。
* **像网页文字一样细腻划选**：鼠标悬停在文字区域自动切换为工字光标（`I-beam`），按住鼠标左键可**任意圈选单字、词组、子片段或跨行选词**，呈现淡蓝色半透明选区。
* **快捷复制**：选定后松开鼠标自动浮出「📋 复制文本」气泡，亦可直接按 **`Ctrl + C`** 写入剪贴板；双击文字可秒选整行。

### 2. 专业矢量标注画板（Annotation System）
* 截图拉框后点击工具条“**✏️ 标注**”（或在贴图上按 **`空格键`**），即刻展开全功能标注工具箱：
  * **⬜ 矩形 / ⭕ 椭圆**：支持实心填充与线框；
  * **↗️ 几何箭头**：智能动态计算角度，精准指向要点；
  * **✏️ 画笔涂鸦**：自由平滑拟合曲线；
  * **🖍️ 荧光笔（马克笔）**：半透明高亮，重点批注不遮挡底层文字；
  * **🔤 动态文字标注**：支持任意位置点击输入、自由拖动平移、拉伸缩放手柄无级调节字号；
  * **🏁 智能马赛克**：局部像素化模糊，隐私信息随心遮蔽；
  * **↩️ 撤销 / ↪️ 重做**：支持 `Ctrl + Z` / `Ctrl + Y` 多步历史回退栈；
  * **🎨 调色板与粗细**：经典 8 色快捷切换 + 自由取色器 + 动态反馈画笔粗细圆形光标。

### 3. 像素级放大镜与精准取色器（Magnifier HUD）
* **8x 像素网格**：截图未选框状态下，光标周围实时跟随跟随式像素放大镜与十字准星。
* **一键复制颜色（`C` 键）**：随时按 **`C`** 键，快速提取准星处的像素色值到剪贴板。
* **双格式自由切换（`Shift` 键）**：按 **`Shift`** 键，在 `#RRGGBB` (HEX) 与 `rgb(r, g, b)` 格式之间无缝切换。

### 4. Win32 智能窗口吸附（Smart Window Snapping）
* 移动鼠标时，底层 Win32 DWM API 会自动探测光标下方的活动窗口与系统控件几何轮廓，以蓝色虚线高亮吸附。
* **单击左键**：无需繁琐拖拽拉框，直接精准捕获当前窗口。

### 5. 高级贴图交互（Pin to Screen）
* **立体环境光阴影**：贴图自带高质感白灰柔光阴影（在深色/浅色背景均醒目且层次分明），支持右键菜单随时开关与偏好持久化。
* **`F4` 鼠标穿透描摹模式**：贴图半透明悬浮置顶，鼠标点击完全穿透并可直接操作底层网页或应用软件。
* **几何变换**：按 **`1` / `2`** 逆时针/顺时针旋转 90 度（OCR 选区自适应重算）；按 **`3` / `4`** 水平/垂直镜像翻转。
* **无级缩放与调透明度**：滚轮平滑缩放尺寸；`Ctrl + 滚轮` 调节贴图透明度。

## ⌨️ 快捷键与操作速查

| 功能 | 快捷键 / 鼠标操作 | 详细说明 |
| :--- | :--- | :--- |
| **屏幕截图** | **`F1`** 或 **左键点击系统托盘图标** | 唤起全屏截图（若被外部软件独占，可点托盘图标） |
| **贴图置顶** | **`F3`** 或 **中键点击系统托盘图标** | 将剪贴板中的图片或纯文本渲染为悬浮贴图 |
| **一键秒贴图** | 截图模式下按 **鼠标中键** | 已拉框则贴选区，未拉框直接将全屏置顶为贴图 |
| **复制放大镜颜色** | 截图未拉框时按 **`C`** 键 | 提取当前十字准星处的像素色值 |
| **切换取色格式** | 截图未拉框时按 **`Shift`** 键 | 在 HEX (`#RRGGBB`) 与 RGB 格式间自由切换 |
| **窗口智能吸附** | 悬停至窗口虚线框后 **单击左键** | 智能选中整个应用程序窗口或控件 |
| **画板标注** | 操作条点“✏️ 标注”，或贴图上按 **`空格键`** | 展开/收起矩形、箭头、文字、马赛克工具栏 |
| **撤销 / 重做** | **`Ctrl + Z`** / **`Ctrl + Y`** | 标注画板历史状态多步回退 |
| **原地划选文字复制** | 鼠标划选贴图文字，按 **`Ctrl + C`** | 微信同款单字/词组级高精度离线 OCR 划词复制 |
| **贴图鼠标穿透** | 贴图获得焦点时按 **`F4`** | 贴图半透明悬浮且鼠标点击穿透至底层（按 F4 恢复） |
| **旋转贴图 90°** | 贴图上按 **`1`** (逆时针) 或 **`2`** (顺时针) | 旋转图片，OCR 选区几何矩阵自动重新映射 |
| **翻转贴图** | 贴图上按 **`3`** (水平翻转) 或 **`4`** (垂直翻转) | 镜像翻转贴图 |
| **缩放 / 透明度** | 鼠标滚轮 / **`Ctrl + 滚轮`** | 贴图等比无级平滑缩放与透明度渐变 |
| **关闭贴图** | 鼠标双击贴图空白处 或 按 **`Esc`** | 安全释放内存并关闭贴图 |

## 🛠️ 本地运行与开发

### 环境要求
* Windows 10 / 11 (64-bit)
* Python 3.10+

### 安装依赖
```bash
pip install -r requirements.txt
```
*(主要依赖包括 `PySide6`, `rapidocr_onnxruntime`, `pywin32`, `numpy`)*

### 运行
```bash
python main.py
```
或直接双击运行项目根目录下的 **`run.bat`** / **`启动.vbs`**（静默后台常驻托盘，无黑框）。
